# room-over
部屋をいっぱいにして稼ごう！ 間取りを作る・買う・貸す・売る。マンション1層から始める不動産経営ゲームです。

ブラウザだけで動きます。インストールは不要です。

▶ 遊ぶ
https://umaisushi.github.io/room-over/

どんなゲーム？

最初に持っているのは、ランダムなマンションの1層だけ。 リノベーションして賃貸サイトに掲載し、家賃収入で物件を増やしていきます。

行動を1つするたびに1ヶ月が進みます。
流行は1年ごとに入れ替わります。
築年数や事故物件は、評価を下げます。
ゴールはありません。資産を増やしつづけるゲームです。
遊び方
メニュー
項目	内容
ゲーム作成	レベルを選んで新しく始めます
つづきから	前回の続きから再開します
ルーム作成	部屋のデザインを自由に作って保存します。ゲーム中のリノベーションや建築で使えます
レベル
レベル	初期資金	特徴

できること

物件

リノベーション：設備を入れ替えます。築年数によるマイナスもリセットされます。
賃貸サイトに掲載：家賃を決めて募集します。高くするほど決まりにくくなります。
売りに出す：価格を決めて売却します。

業者から買う

毎月3件の物件が並びます。
評判の悪い業者からは、隠れた瑕疵や、告知されていない事故物件をつかまされることがあります。

建てる

土地を買い、間取りと設備を決めてマンションを建てます。階数ぶんの部屋が一度に手に入ります。
建築期間は1〜4階で1年。5階以上は1階ごとに+1ヶ月。
4階以上はエレベーターが必須です（+600万円）。
業者から買うよりかなり高くつきます。

事務所

開設すると（300万円、維持費 月5万円）、毎月お客さんが来店します。
希望に合う物件を紹介すると、賃貸サイトより決まりやすく、購入希望者には高く売れます。

カタログ

間取りの見本と、素材の一覧です。今年の流行もここで確認できます。
しくみ
魅力スコア

家賃と評価額は、物件の「魅力スコア」で決まります。各物件の内訳はゲーム内で確認できます。

要素	影響
設備グレード	11分類の設備の質
間取り	洗面と収納があるとプラス
流行	流行中の設備1つにつき+5。流行の間取りタイプなら+10
築浅	築5年未満はプラス
築年数	リノベーションしていない年数ぶんマイナス
和室（畳）	流行中はプラス。流行から遠ざかるほど年々マイナス
瑕疵	マイナス。リノベーションで直せます
事故物件	大きなマイナス
流行
毎年、設備5つと間取りタイプ1つ（1R〜3LDK）が流行になります。
流行に合った物件はスコアが上がり、入居希望者も増えます。
間取り
12×8のマス目（1マス＝約1㎡）に、部屋の種類をなぞって塗ります。
種類：LDK・居間／居室1〜3／キッチン／浴室／洗面／トイレ／収納／玄関
居間か居室、キッチン、浴室、トイレ、玄関がそろうと確定できます。
広さと「1K」「2LDK」などの表記は、塗った内容から自動で決まります。
間取りカタログの見本（11種類）から選んで、手直しすることもできます。

リノベーションでも間取りを変えられますが、高額です。

内容	費用
間取り変更の基本料	100万円
部屋割りの変更	1マスにつき15万円
増築・減築	1マスにつき60万円
素材カタログ

扉／床／壁／キッチン／コンロ／洗面台／トイレ／クローゼット／窓／風呂／棚の11分類。 床は9種類（畳、オーク材、ウォルナット無垢材、ヘリンボーン張り、大理石タイルなど）、壁は10種類（漆喰塗り、珪藻土、レンガタイル、コンクリート打ちっぱなしなど）で、それぞれ質感つきで表示されます。

3D表示
リノベーションや間取りの編集中は、部屋が3Dで表示されます。
ドラッグで回転、ホイールで拡大縮小。設備やマスを変えると、その場で反映されます。
お金まわり
維持費：1部屋につき月1万円
満室ボーナス：2部屋以上を持っていて全室が入居中なら、家賃+5%
入居者が亡くなると事故物件になり、特殊清掃に30万円かかります
資金のマイナスが6ヶ月続くと、倒産でゲームオーバーです
称号

総資産に応じて、見習い大家 → 中堅大家 → 敏腕オーナー → 不動産王 → ROOM OVER! レジェンド と上がっていきます。
